## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 담당자 | 김무성 |
| 역할 | 온톨로지 설계, SPARQL 추론 규칙 작성, 검증 자동화 |
| 플랫폼 | Cloud Functions Python (Stateless) |

| 기술 | 용도 |
|------|------|
| Python + RDFLib | 온톨로지 로드/저장/SPARQL 추론 실행 |

| Firestore | 추론 결과 저장 (quests, room_objects, persona) |
| FCM | 신규 퀘스트 푸시 알림 |

## 3. 온톨로지 스키마 현황

### 3-1. 클래스 목록 (27개)

#### 핵심 데이터 클래스 (11개)

| 클래스 | 설명 |
|--------|------|
| `User` | 앱 사용자. uid로 식별, 모든 데이터의 중심 노드 |
| `SleepData` | Health Connect 수면 기록 (하루 단위) |
| `StepCount` | Health Connect 걸음수 기록 (날짜별) |
| `AppUsage` | Android UsageStats 앱 사용 시간 기록 |
| `GalleryPhoto` | Gemma 3n 온디바이스 분석 갤러리 사진 (EXIF 포함) |
| `Location` | GPS 방문 장소 기록 (역지오코딩 장소명 포함) |
| `Activity` | 사용자 활동 기록 (걷기/운동/식사/독서 등) |
| `Quest` | 추론 엔진 생성 퀘스트 (삶 개선형 / 데이터 보완형) |
| `Reward` | 퀘스트 완료 보상 (Unity 상점 사용) |
| `Persona` | 추론 규칙(P1~P6)으로 자동 생성되는 사용자 성격 요약 |
| `RoomObject` | 추론 결과로 생성되는 Unity 3D 방 오브젝트 |

#### 확장 데이터 소스 클래스 (3개)

| 클래스 | 설명 |
|--------|------|
| `MusicListening` | Spotify·멜론 음악 청취 기록 (트랙/아티스트/장르) |
| `CalendarEvent` | 캘린더 일정 기록 (시작/종료 시각, 반복 여부) |
| `Weather` | OpenWeatherMap 날씨 정보 (GPS 위치 기반) |

#### 추론 상태 클래스 (13개)

| 클래스 | 생성 조건 |
|--------|-----------|
| `FatigueRisk` | 수면 6h 미만 + 카페인 과다 (Rule 1) |
| `BurnoutWarning` | FatigueRisk + 운동 퀘스트 미완료 지속 (Rule 2, 13) |
| `SedentaryPattern` | 연속 3일 걸음수 3,000보 미만 (Rule 3) |
| `PlaceHabit` | 같은 장소 3회 이상 방문 (Rule 4) |
| `IndoorDayPattern` | 비/겨울 + 외출 2곳 미만 (Rule 7) |
| `Routine` | 같은 시간대 일정 주 3회 이상 (Rule 8) |
| `MusicMood` | 특정 장르 하루 2시간 이상 청취 (Rule 9) |
| `SleepQualityImpaired` | 오후 카페인 + 수면질 60 미만 (Rule 10, 인과 체인) |
| `ExerciseSkipped` | SleepQualityImpaired + 운동 기록 없음 (Rule 11) |
| `WeeklyActivityLow` | ExerciseSkipped + 주간 저보행 3일 (Rule 12) |
| `FocusMode` | 클래식·Lo-fi 3시간 이상 연속 청취 (Rule 26) |
| `StressIndicator` | 헤비메탈·록 야간(22h+) 청취 (Rule 27) |
| `SocialActivity` | 댄스·팝 청취 + 외출 동시 발생, 3h 이내 (Rule 28) |
| `ScheduleOverload` | 하루 일정 5개 이상 (Rule 29) |

### 3-3. OWL 제약조건

#### owl:disjointWith (7쌍)
- `SleepData` ↔ `StepCount`

- `FocusMode` ↔ `StressIndicator`

## 4. 추론 규칙 현황

총 **29개 규칙** (`inference_rules.sparql`)

### 4-1. 건강/활동 상태 추론 (Rules 1~4)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `fatigue_risk` | 수면 < 6h + 주간 카페 3회 초과 OR 야간 카페 1회 초과 OR 주말 카페인 점수 ≥ 4.5 | `FatigueRisk` + `tired_pillow` RoomObject |
| `burnout_warning` | FatigueRisk + 운동 퀘스트 미완료 ≥ 3건 | `BurnoutWarning` + 스트레칭 퀘스트 (50코인) |
| `sedentary_pattern` | `hasConsecutiveLowStepDays` ≥ 3 (DuckDB 전처리) | `SedentaryPattern` + 산책 퀘스트 (50코인) + `running_shoes` RoomObject |
| `place_habit` | 같은 placeType 방문 ≥ 3회 | `PlaceHabit` + placeType 매핑 RoomObject (5종) |

> **place_habit objectType 매핑**: cafe→coffee_cup(desk), gym→dumbbell(floor), library→bookshelf(wall), park→tree_pot(floor), 기타→generic_marker(floor)
> STR() 래핑으로 typed literal(xsd:string) / plain literal 모두 호환 (#96)

### 4-2. 인과관계 / 수면 추론 (Rule 5, 10~13)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `late_caffeine_sleep_quality` | 카페 18h 이후 방문 + 수면질 < 60 | 디카페인 권장 퀘스트 (50코인) |
| `causal_sleep_impaired` | 카페 18h 이후 + 수면질 < 60 | `SleepQualityImpaired` (체인 1단계) |
| `causal_exercise_skipped` | SleepQualityImpaired + 운동 기록 없음 | `ExerciseSkipped` (체인 2단계) |
| `causal_weekly_activity_low` | ExerciseSkipped + 저보행 ≥ 3일 | `WeeklyActivityLow` (체인 3단계) |
| `causal_burnout_from_chain` | WeeklyActivityLow | `BurnoutWarning` + 산책 퀘스트 (50코인) (체인 종점) |

### 4-3. 데이터 보완형 퀘스트 (빈 노드 감지, Rules 6계열)

| Rule ID | 빈 속성 | 생성 퀘스트 | 보상 |

| `missing_emotion` | Activity.emotion 없음 | "오늘 [activityType] 어떤 기분이었어?" | 30코인 |
| `missing_purpose` | 3회+ 방문 장소에 purpose 없음 | "[장소]에 자주 가는 이유가 있어?" | 30코인 |
| `missing_music_mood` | MusicListening.mood 없음 | "요즘 [genre] 음악 자주 듣네, 어떤 기분일 때 들어?" | 30코인 |
| `missing_sleep_cause` | 수면질 < 60인데 cause 없음 | "어젯밤 잠이 잘 안 왔어? 이유가 있었어?" | 30코인 |
| `missing_event_review` | 종료된 CalendarEvent에 review 없음 | "[eventTitle] 어땠어?" | 30코인 |
