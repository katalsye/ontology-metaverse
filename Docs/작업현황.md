## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 담당자 | 김무성 |
| 역할 | 온톨로지 설계, SPARQL 추론 규칙 작성, 검증 자동화 |
| 플랫폼 | Cloud Functions Python (Stateless) |
| 네임스페이스 | `prod: <http://7team.dev/ontology#>` |

### 기술 스택

| 기술 | 용도 |
|------|------|
| Python + RDFLib | 온톨로지 로드/저장/SPARQL 추론 실행 |
| SPARQL 1.1 | 추론 규칙 작성 (CONSTRUCT 방식) |
| DuckDB | 트리플 집계: 연속 저보행 일수, 주말 카페인 가중치 |
| Firebase Storage | 온톨로지 그래프 `.ttl` 직렬화 저장 (버전 관리 포함) |
| Firestore | 추론 결과 저장 (quests, room_objects, persona) |
| FCM | 신규 퀘스트 푸시 알림 |

## 3. 온톨로지 스키마 현황

### 3-1. 클래스 목록 (27개)

#### 핵심 데이터 클래스 (11개)

| 클래스 | 설명 |
|--------|------|
| `User` | 앱 사용자. uid로 식별, 모든 데이터의 중심 노드 |
| `SleepData` | Health Connect 수면 기록 (하루 단위) |
| `StepCount` | Health Connect 걸음수 기록 (날짜별) |
| `AppUsage` | Android UsageStats 앱 사용 시간 기록 |
| `GalleryPhoto` | Gemma 3n 온디바이스 분석 갤러리 사진 (EXIF 포함) |
| `Location` | GPS 방문 장소 기록 (역지오코딩 장소명 포함) |
| `Activity` | 사용자 활동 기록 (걷기/운동/식사/독서 등) |
| `Quest` | 추론 엔진 생성 퀘스트 (삶 개선형 / 데이터 보완형) |
| `Reward` | 퀘스트 완료 보상 (Unity 상점 사용) |
| `Persona` | 추론 규칙(P1~P6)으로 자동 생성되는 사용자 성격 요약 |
| `RoomObject` | 추론 결과로 생성되는 Unity 3D 방 오브젝트 |

#### 확장 데이터 소스 클래스 (3개)

| 클래스 | 설명 |
|--------|------|
| `MusicListening` | Spotify·멜론 음악 청취 기록 (트랙/아티스트/장르) |
| `CalendarEvent` | 캘린더 일정 기록 (시작/종료 시각, 반복 여부) |
| `Weather` | OpenWeatherMap 날씨 정보 (GPS 위치 기반) |

#### 추론 상태 클래스 (13개)

| 클래스 | 생성 조건 |
|--------|-----------|
| `FatigueRisk` | 수면 6h 미만 + 카페인 과다 (Rule 1) |
| `BurnoutWarning` | FatigueRisk + 운동 퀘스트 미완료 지속 (Rule 2, 13) |
| `SedentaryPattern` | 연속 3일 걸음수 3,000보 미만 (Rule 3) |
| `PlaceHabit` | 같은 장소 3회 이상 방문 (Rule 4) |
| `IndoorDayPattern` | 비/겨울 + 외출 2곳 미만 (Rule 7) |
| `Routine` | 같은 시간대 일정 주 3회 이상 (Rule 8) |
| `MusicMood` | 특정 장르 하루 2시간 이상 청취 (Rule 9) |
| `SleepQualityImpaired` | 오후 카페인 + 수면질 60 미만 (Rule 10, 인과 체인) |
| `ExerciseSkipped` | SleepQualityImpaired + 운동 기록 없음 (Rule 11) |
| `WeeklyActivityLow` | ExerciseSkipped + 주간 저보행 3일 (Rule 12) |
| `FocusMode` | 클래식·Lo-fi 3시간 이상 연속 청취 (Rule 26) |
| `StressIndicator` | 헤비메탈·록 야간(22h+) 청취 (Rule 27) |
| `SocialActivity` | 댄스·팝 청취 + 외출 동시 발생, 3h 이내 (Rule 28) |
| `ScheduleOverload` | 하루 일정 5개 이상 (Rule 29) |

## 4. 추론 규칙 현황

총 **29개 규칙** (`inference_rules.sparql`)

### 4-1. 건강/활동 상태 추론 (Rules 1~4)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `fatigue_risk` | 수면 < 6h + 주간 카페 3회 초과 OR 야간 카페 1회 초과 OR 주말 카페인 점수 ≥ 4.5 | `FatigueRisk` 상태 부여 |
| `burnout_warning` | FatigueRisk + 운동 퀘스트 미완료 ≥ 3건 | `BurnoutWarning` + 스트레칭 퀘스트 |
| `sedentary_pattern` | `hasConsecutiveLowStepDays` ≥ 3 (DuckDB 전처리) | `SedentaryPattern` + 산책 퀘스트 |
| `place_habit` | 같은 placeName 방문 ≥ 3회 | `PlaceHabit` + RoomObject 생성 |

### 4-2. 인과관계 / 수면 추론 (Rule 5, 10~13)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `late_caffeine_sleep_quality` | 카페 18h 이후 방문 + 수면질 < 60 | 디카페인 권장 퀘스트 |
| `causal_sleep_impaired` | 카페 18h 이후 + 수면질 < 60 | `SleepQualityImpaired` (체인 1단계) |
| `causal_exercise_skipped` | SleepQualityImpaired + 운동 기록 없음 | `ExerciseSkipped` (체인 2단계) |
| `causal_weekly_activity_low` | ExerciseSkipped + 저보행 ≥ 3일 | `WeeklyActivityLow` (체인 3단계) |
| `causal_burnout_from_chain` | WeeklyActivityLow | `BurnoutWarning` + 산책 퀘스트 (체인 종점) |

### 4-3. 데이터 보완형 퀘스트 (빈 노드 감지, Rules 6계열)

| Rule ID | 빈 속성 | 생성 퀘스트 |
|---------|---------|-------------|
| `missing_companion` | Location.companion 없음 | "오늘 [장소] 누구랑 갔어?" |
| `missing_emotion` | Activity.emotion 없음 | "오늘 [activityType] 어떤 기분이었어?" |
| `missing_purpose` | 3회+ 방문 장소에 purpose 없음 | "[장소]에 자주 가는 이유가 있어?" |
| `missing_music_mood` | MusicListening.mood 없음 | "요즘 [genre] 음악 자주 듣네, 어떤 기분일 때 들어?" |
| `missing_sleep_cause` | 수면질 < 60인데 cause 없음 | "어젯밤 잠이 잘 안 왔어? 이유가 있었어?" |
| `missing_event_review` | 종료된 CalendarEvent에 review 없음 | "[eventTitle] 어땠어?" |

### 4-4. 날씨/장소 패턴 추론 (Rules 7, 14)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `indoor_day_pattern` | 비(rain) OR 겨울(12·1·2월) + 외출 < 2곳 | `IndoorDayPattern` 상태 |
| `sunny_indoor_quest` | IndoorDayPattern + 맑은 날씨(sun/clear) | 강화 산책 퀘스트 |

### 4-5. 루틴 / 음악 감정 추론 (Rules 8, 9)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `routine_detection` | 같은 시간대(hour) 일정 ≥ 3회 | `Routine` + routineHour + RoomObject |
| `music_mood` | 특정 장르 하루 합계 ≥ 120분 | `MusicMood` + moodGenre |

### 4-6. Spotify 음악 패턴 추론 (Rules 26~28)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `focus_music_pattern` | 클래식·Lo-fi ≥ 180분 | `FocusMode` + 책상 조명 RoomObject |
| `stress_music_pattern` | 헤비메탈·록 + 22h 이후 청취 | `StressIndicator` + 보완형 퀘스트 |
| `social_music_pattern` | 댄스·팝 + 외출 위치 동시 발생 + 3h 이내 | `SocialActivity` + 파티 조명 RoomObject |

### 4-7. 일정 과부하 추론 (Rule 29)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `schedule_overload` | 같은 날 CalendarEvent ≥ 5개 | `ScheduleOverload` + 휴식 권장 퀘스트 |

### 4-8. 페르소나 자동 생성 (Rules P1~P6)

| Rule ID | 조건 | 결과 |
|---------|------|------|
| `persona_active` | 걸음수 ≥ 7,000보 기록 ≥ 4일 | Persona.energyType = "active" |
| `persona_indoor` | IndoorDayPattern 활성 | Persona.energyType = "indoor" |
| `persona_social` | companion 있는 방문 ≥ 3회 | Persona.socialPreference = "social" |
| `persona_solitary` | 혼자 방문 비율 ≥ 70% | Persona.socialPreference = "solitary" |
| `persona_routine` | Routine 노드 ≥ 2개 | Persona.lifePattern = "routine" |
| `persona_night_owl` | 23h~02h 방문 ≥ 3회 | Persona.lifePattern = "night_owl" |

### 4-9. 규칙 실행 순서 (RULE_ORDER)
```
fatigue_risk → burnout_warning → sedentary_pattern → place_habit

→ indoor_day_pattern → sunny_indoor_quest
→ routine_detection → music_mood
→ focus/stress/social_music_pattern → schedule_overload
→ causal_sleep_impaired → causal_exercise_skipped
→ causal_weekly_activity_low → causal_burnout_from_chain
→ persona_active → persona_indoor → persona_social
→ persona_solitary → persona_routine → persona_night_owl
```
